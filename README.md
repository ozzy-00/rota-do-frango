# 🍗 Rota do Frango — Cardápio Digital

Cardápio digital desenvolvido para a **Rota do Frango**, um negócio de frango assado que busca facilitar a visualização dos produtos e o contato dos clientes para realizar pedidos pelo WhatsApp.

## 📌 Sobre o projeto

O projeto tem como objetivo apresentar os produtos, combos, acompanhamentos e preços de forma simples, organizada e acessível, proporcionando uma experiência prática para os clientes.

O cardápio foi desenvolvido para uso comercial real, aplicando conhecimentos de desenvolvimento web na criação de uma solução digital para um pequeno negócio.

## 🎯 Objetivos

- Apresentar os produtos e combos disponíveis.
- Facilitar o acesso aos preços e aos acompanhamentos.
- Permitir que os clientes entrem em contato pelo WhatsApp.
- Disponibilizar o cardápio pela internet.
- Aplicar conhecimentos de tecnologia na solução de uma necessidade real.

## 🛠️ Tecnologias

- **HTML5** — estruturação do conteúdo da página.
- **CSS3** — estilização e apresentação visual, caso utilizado no projeto.
- **JavaScript** — interatividade, caso utilizado no projeto.
- **GitHub** — versionamento e armazenamento do código-fonte.
- **Vercel** — publicação e hospedagem do cardápio digital.

## ✨ Funcionalidades

- Visualização do cardápio digital.
- Apresentação de produtos, preços e combos.
- Informações sobre os acompanhamentos.
- Acesso ao WhatsApp para contato e pedidos.
- Consulta online pelo navegador.

## 🚀 Acesso ao projeto

- **Repositório:** https://github.com/ozzy-00/rota-do-frango
- **Cardápio online:** https://cardapio--rota-do-frango-5.vercel.app/

## 💻 Como executar localmente

1. Clone este repositório:

   ```bash
   git clone https://github.com/ozzy-00/rota-do-frango.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd rota-do-frango
   ```

3. Abra o arquivo `index.html` no navegador.
